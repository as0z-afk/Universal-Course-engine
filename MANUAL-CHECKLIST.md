# Manual Browser Checklist

- [ ] Open `index.html` directly from disk.
- [ ] Confirm initial sample lessons render and navigation is populated.
- [ ] Open the editor, replace the source, and apply a course with several `##` headings.
- [ ] Confirm the sidebar title, lesson list, counts, practice cards, glossary, and concept map update.
- [ ] Switch through Beginner, Standard, Deep-Dive, Revision, and Conversational modes.
- [ ] Test `Q:` / `A:` practice, card reveal, previous/next, and shuffle.
- [ ] Search lesson text, glossary entries, and source passages.
- [ ] Add a note, navigate to another lesson, return, and export notes.
- [ ] Test arithmetic inputs: `(12 + 8) / 4`, `2^5`, malformed expressions, and division by zero.
- [ ] Export Markdown and download the HTML app.
- [ ] Test the sidebar on desktop and a narrow/mobile viewport.
- [ ] Test keyboard focus, Escape closing the mobile sidebar, reduced motion, and print preview.
- [ ] Confirm pasted text containing HTML-like strings renders as text rather than executing.
